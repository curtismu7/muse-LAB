One airline back end, any agent

Pick a client. Each one adds the same Airline Connector, signs Sam in at PingOne, and calls the same gateway. Only the client and the name PingOne shows change.

What the back end did

    The same code runs for every client: Muse's /mcp and /connector/*, the PingOne DaVinci flow (Protect, agent detected, consent), the on-behalf-of exchange and the gateway. The client only changes its name, its callback, and which PingOne app signs Sam in (its own when it has one).
